# CreatersDen Website

Static, multipage website project for CreatersDen, a video-editing and creative post-production agency.

## Current state

The discovery, reference review, design-direction exploration, typography direction, and color palette are approved and documented. Production code has not yet been scaffolded. See:

- [`PROGRESS.md`](PROGRESS.md) for a factual account of completed work.
- [`HANDOFF.md`](HANDOFF.md) for the complete continuation brief.
- [`instructions.md`](instructions.md) for operating rules that another LLM or developer should read first.
- [`PROJECT.md`](PROJECT.md) for the living project brief and decision log.
- [`docs/REFERENCES.md`](docs/REFERENCES.md) for the reference-site analysis.

## Approved direction

- Structure: **Direction D — The Den**
- Display typography: **Direction A's bold uppercase grotesk treatment**
- Supporting type roles: editorial serif, readable sans-serif, and monospace timecode/UI details
- Palette: **Cinder & Ember**
- Hosting: GitHub Pages initially; custom domain later
